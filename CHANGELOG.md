# Changelog

## Unreleased

## 0.1.0 - Initial Release

### Added
- Initial support for Railroader's Relay scripting language (`.rl`) in VS Code.
- Syntax highlighting for keywords, variables, functions, comments, strings, and operators.
- Basic editor support, including automatic indentation, bracket matching, and code folding.
- Snippets for common Relay scripting patterns.
- Basic autocomplete and hover information for some of the Railroader Relay APIs.

### Known Limitations
- No syntax or error checking at this time.
- Autocomplete and API documentation are limited and will be expanded in future updates.
- No type checking or advanced IntelliSense support.
